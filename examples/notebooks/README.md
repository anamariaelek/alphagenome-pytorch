# Splicing finetuning

This document describes the workflow of splicing project: preparing
splice-site usage data, finetuning AlphaGenome on it, evaluating predictions,
clustering developmental trajectories, comparing across species, and inspecting model
attributions. Shared code lives in three places: plotting functions in
[`src/alphagenome_pytorch/plotting/splicing.py`](../../src/alphagenome_pytorch/plotting/splicing.py),
data loading / metric computation in
[`src/alphagenome_pytorch/evaluation/splicing.py`](../../src/alphagenome_pytorch/evaluation/splicing.py),
and trajectory-clustering logic in
[`src/alphagenome_pytorch/clustering.py`](../../src/alphagenome_pytorch/clustering.py);
 command-line steps (prediction, clustering) are under
[`scripts/`](../../scripts/) — see [`scripts/README.md`](../../scripts/README.md) for
the full reference.

## Data preparation

| Notebook/script | Purpose |
|---|---|
| [`splice_usage_data.ipynb`](splice_usage_data.ipynb) | Explores the raw ground-truth splice-site annotation and usage data (Ensembl GTF vs. Mazin et al.), parses per-condition usage parquet files, summarizes site counts/support per species and tissue, and does an early look at developmental dynamics and tissue-specific sites directly from the observed data (no model predictions). Largest and most foundational notebook — start here to understand the input data. |

## Finetuning

| Notebook/script | Purpose |
|---|---|
| [`scripts/finetune_splice.py`](../../scripts/finetune_splice.py) and the [`scripts/finetune_splice_submit_*.sh`](../../scripts/finetune_splice_submit.sh) | Finetuning AlphaGenome on splice classification/usage: loads the pretrained model, builds the splice dataset/dataloader (with the multi-species sampler), and runs a training loop. |

## Model evaluation

Predictions are generated by `scripts/evaluate_splice.py` (driven by
`scripts/evaluate_splice_submit.sh`), which writes `predictions_<species>.npz`
(classification) and `usage_<species>.npz` (usage) per species under
`<model_dir>/preds_<subset>/<species>/`.

| Notebook/script | Purpose |
|---|---|
| [`splice_model_eval.ipynb`](splice_model_eval.ipynb) | Main evaluation entry point. Loads classification metrics (AUPRC per class/species/subset) and usage correlations (Pearson r per species/tissue), including cross-model and cross-species-head comparisons, then parses raw per-site predictions into `predictions.parquet` / usage arrays for the two notebooks below. |
| [`splice_genomic_overlap.ipynb`](splice_genomic_overlap.ipynb) | Continues from the parsed predictions: overlaps splice sites with GTF features (CDS/UTR/exon) and reports classification AUPRC / usage Pearson r broken down by genomic feature category, per species. |
| [`splice_developmental_dynamics.ipynb`](splice_developmental_dynamics.ipynb) | Continues from the parsed usage predictions: computes per-site trajectory correlations, plots example site trajectories (top-correlated and tissue-specific), classifies sites as developmentally dynamic vs. stable, and reports prediction accuracy by dynamics subclass and by timepoint. |
| [`splice_model_eval_compare_lora.ipynb`](splice_model_eval_compare_lora.ipynb) | Compares classification/usage accuracy across LoRA finetuning ranks (e.g. rank 8 vs. 16 vs. 32, human-only vs. multi-species). |
| [`splice_model_eval_compare_multi_species.ipynb`](splice_model_eval_compare_multi_species.ipynb) | Compares classification/usage accuracy across training species combinations (human, human+mouse, human+mouse+rat, ... up to all five). |


## Developmental-trajectory clustering

| Notebook/script | Purpose |
|---|---|
| `scripts/cluster_trajectories.py`| Clustering of _observed_ developmental SSE trajectories with Gaussian-process smoothing + Ward hierarchical clustering, then annotates each cluster with a shape label (`up_early`, `down_late`, `flat_high`, ...). |
| [`splice_trajectory_clustering.ipynb`](splice_trajectory_clustering.ipynb) | Notebook equivalent of clustering script above, for interactive analysis. |
| `scripts/cluster_predictions.py`| Clustering of predicted trajectories against the reference (observed) clusters. 
| [`splice_prediction_clustering.ipynb`](splice_prediction_clustering.ipynb) | Evaluates *predicted* trajectories against the reference (observed) clustering (as produced by `scripts/cluster_predictions.py`), including shape concordance, agreement vs. coverage/centroid distance, per-species and per-tissue breakdowns. |



True (observed) developmental trajectories are clustered using `scripts/cluster_trajectories.py`, and the results are saved to specified output directory `<ref>/<species>/<tissue>`.

Example: clustering trajectories for 4 organs in 5 species:

```bash
ref=/home/elek/sds/sd17d003/Anamaria/gp_splice_usage/
mkdir -p ${ref}
python scripts/cluster_trajectories.py \
    --species human mouse rat rabbit opossum \
    --tissue  Brain Cerebellum Liver Testis \
    --output ${ref} > ${ref}/cluster_predictions.log 2>&1
```
Predicted developmental trajectories are clustered using `scripts/cluster_predictions.py` and the results are saved in the model predictions directory.

Example: clustering trajectories from `<model>` predictions for 4 organs in 5 species against reference (observed) trajectories saved in `<ref>`.
```bash
ref=/home/elek/sds/sd17d003/Anamaria/gp_splice_usage/
model=lora_32_human_mouse_rat_rabbit_opossum
model_dir=/home/elek/sds/sd17d003/Anamaria/alphagenome_genomicsxai/${model}
preds_dir=${model_dir}/preds_all_intersect_protein_coding
for species in human mouse rat rabbit opossum; do
    for tissue in Brain Cerebellum Liver Testis; do
        out=${PREDS_DIR}/${SPECIES}/pred_gp_splice_usage/${tissue}
        mkdir -p ${OUT}
        python scripts/cluster_predictions.py \
            --species ${species} \
            --tissue ${tissue} \
            --ref-dir ${ref} \
            --output ${out} > ${out}/cluster_predictions.log 2>&1
        echo "Running clustering predictions for ${species} ${tissue}"
    done
done
```

## Cross-species comparison

These use whole-genome alignments (`liftover_splice_hal.py`, HAL/multiz) to map splice
sites between species and compare usage/predictions at orthologous positions.

| Notebook/script | Purpose |
|---|---|
| [`splice_cross_species_usage.ipynb`](splice_cross_species_usage.ipynb) | Lifts human splice sites over to other species via the alignment cache and compares mean usage/accuracy at aligned positions per timepoint, flagging sites with divergent usage (high in human, low elsewhere) that are still well predicted. |
| [`splice_cross_species_usage_trajectory.ipynb`](splice_cross_species_usage_trajectory.ipynb) | Same lift-over approach but at the trajectory-shape level: matches aligned coordinates in other species to the human observed cluster shapes to see whether trajectory shape is conserved. |
| [`splice_cross_species_divergence.ipynb`](splice_cross_species_divergence.ipynb) | Focused follow-up: starting from orthologous, well-predicted human sites, finds cases where the developmental role diverges (opposite direction of change) in another species, with gene-level orthology context and example trajectory plots. |

## Attributions

| Notebook/script | Purpose |
|---|---|
| [`splice_attributions.ipynb`](splice_attributions.ipynb) | Computes and compares in-silico attribution methods (e.g. ISM, gradient-based) for splice classification and usage predictions at selected sites, including cross-species aligned attributions and a sequence-swap validation check. |
